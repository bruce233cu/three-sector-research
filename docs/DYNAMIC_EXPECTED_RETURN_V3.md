# 动态期望收益 V3 升级说明

## 已实现闭环

产业变化 → 公司映射 → 参数级利润模型 → 三情景估值与概率 → 价格快照 → 动态期望收益 → 历史快照 → 预测验证。

## 核心公式

- 三情景利润由底层参数自动推导，禁止直接填写最终利润。
- 情景收益率 = 目标市值 ÷ 当前市值 - 1。
- 期望收益 = Σ（情景收益率 × 情景概率）。
- 年化期望收益 = (1 + 期望收益)^(1 / 距离兑现年数) - 1。
- 风险收益比 = 期望收益 ÷ 最大假设下行绝对值。
- 价格变化只改变收益空间；利润模型和情景概率只由基本面证据改变。

## 新增数据结构

- `model_parameters`：参数、单位、类型、来源、证据等级、确认状态、推算逻辑。
- `probability_assessments` / `probability_changes`：离散概率与每次调整历史。
- `price_snapshots`：可追溯收盘价与市值。
- `expected_return_snapshots`：每日动态期望收益和完整计算轨迹。
- `sensitivity_results`：关键变量敏感性。
- `prediction_validations`：30/90/180日和一年后验证。
- `model_change_log`：模型版本与变化原因。
- `latest_expected_returns` / `reverse_valuation_requirements`：最新期望收益和反向估值视图。
