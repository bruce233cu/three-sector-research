# 第一轮历史验证统计合同

False Positive（误报）、Miss（漏报）、Lag（识别滞后）、Churn（状态反复）、PIT（时点真实性）只在评估层使用。Baseline V1引擎、规则、参数和状态机保持起始提交的字节不变。

- 正样本漏报：前窗、事件和后窗合计从未观察到S2。事件期检出另列；后窗确认属于事件外确认，不混成全窗漏报。
- 负样本：事件期S2行业日、连续S2至少3日、S1→S2新增确认、S3→S2恢复、事件起点继承S2分别统计。前后窗可能属于其他真实行情，不自动计作事件误报。
- 滞后：真实交易日索引差，事件首日为0，负数保留。首次观察不等于第一次真实进入，窗口首日已有S1/S2标记左截断。未确认保持NULL，不进入已确认者中位数；不得把前一生命周期的负滞后直接说成提前识别本次主线。
- 状态反复：每日真实硬转换，包含窗口第一日已知前态的转换。重新访问已见状态算反复；距最近一次观察不超过5交易日算短间隔反复。另列相邻A→B→A、20日最大转换。这些计数自身不判好坏。
- 生命周期：ID去重，所有候选周期重入和S4→S1重入分开。候选失败关闭不是S4退潮。窗口末开放周期标记右截断；没有独立结构恶化参考日期时，退潮滞后保持NULL，不补造答案。
- Freeze：冻结日、理由、恢复方式与冻期硬转换违规数分别统计。未知谓词保持NULL，冻期违规应为0。
- 覆盖：成分解析与有效价格比例分开；基准值与基准截面覆盖分开；必需指标、叠加指标、规则记录与已知谓词比例分开。递延指标保持NULL，未验证知识时间占比100%，strict PIT覆盖0%。
- 确认后收益：确认日收盘之后累计5/10/20/60真实交易日相对基准收益，超过窗口或档案末端为右截断、NULL。5/10日假突破：出现S3/S4且终点未回S2。
- 分层保留样本类型、风格、行情环境、主线类别和事件簇。相同行业或重叠窗口相关，跨case求和是案例观察量，不当作独立证券日或总体准确率，不创建综合分数。

缺预热的冷启动版本保留为诊断，不作为完整Baseline验收。补数只恢复原认证字节对应的84日：原成功源原始响应校验必须一致，原失败源保持缺失，历史成分和股票池复用，84日基准重算必须与认证记录一致。新run和数据版本不覆盖旧诊断。

时点检查覆盖成分、股票池、价格、成交、基准、均线、分位、生命周期和后验标签。未来扰动不变性、每日成分、仅用历史收益重算和checkpoint日期检查互补；这些不代替个股历史知识时间的独立证明。
